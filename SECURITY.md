# Security

Scrawl is designed to keep microphone audio and transcripts on your Mac. Security reports are welcome, especially reports involving data leaving the device, unsafe model or update handling, permissions, signing, or release artifacts.

Please do not open a public issue for a suspected vulnerability or include private transcripts, recordings, model files, credentials, or logs containing sensitive data.

Use GitHub's private vulnerability reporting to send a report:

<https://github.com/Jetemple/Scrawl/security/advisories/new>

Include the affected version, macOS version, reproduction steps, impact, and a minimal proof of concept when safe. We will acknowledge reports and coordinate disclosure through GitHub.
